# userscripts

个人使用的本地脚本。

[English](README.md)

## 安装

1. 安装 [Violentmonkey](https://violentmonkey.github.io/) 或 Tampermonkey。
2. 打开本仓库里的 `.user.js`。

| 文件 | 站点 | 做什么 |
|---|---|---|
| [`nodeseek-checkin.user.js`](nodeseek-checkin.user.js) | [nodeseek.com](https://www.nodeseek.com/) | 已登录时每日签到 |
