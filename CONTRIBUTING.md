# Contributing

```text
main (protected)
  → feat/* | fix/* | docs/*
  → Conventional Commit
  → PR
  → squash merge
```

Do not commit on `main`. Do not publish these scripts to Greasy Fork.

Commit format: `type(scope): imperative summary`.
Allowed types: `feat` `fix` `refactor` `docs` `test` `chore`.
